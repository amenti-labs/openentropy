# Legacy Docs Mirror

The canonical user-facing documentation IA lives in:

- `website/src/content/docs/**`
- navigation configured in `website/astro.config.mjs`

Files in this `docs/` directory are retained as a repository-local mirror and for
historical compatibility. When user-visible behavior changes, update canonical
website docs first, then synchronize any relevant mirror pages.

See `docs/DOCS_STANDARDS.md` and `AGENTS.md` for policy details.
